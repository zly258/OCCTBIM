## 🎯 核心特性

### 📐 建模功能
- **2D绘图**: 点、线、圆、弧、矩形、多边形等基本图形
- **3D建模**: 立方体、球体、圆柱体等基本立体和特征建模
- **注释标注**: 文字、表格、各种尺寸标注
- **块系统**: 块定义、块引用和嵌套块支持

### 🏗️ BIM专业模块
- **HVAC暖通**: 风管系统、设备建模、系统管理
- **管道系统**: 管道建模、管件库、智能连接
- **结构建模**: 钢结构、型钢库、构件管理
- **PID符号**: 工艺流程图符号定义和管理

### 🔧 系统架构
- **分层架构**: 表现层、应用层、业务层、核心层清晰分离
- **模块化设计**: 功能模块独立，支持插件化扩展
- **扩展机制**: 实体、工具、动作、数据多维度扩展支持
- **属性系统**: 完整的属性定义、编辑器和验证机制

### 💾 数据管理
- **SQLite存储**: 高效的本地数据库存储
- **多格式支持**: JSON、DXF、STEP、IGES等格式
- **扩展数据**: 灵活的自定义属性系统
- **事务管理**: 完整的撤销重做和事务支持

### 🎨 用户界面
- **现代界面**: Ribbon界面和停靠面板系统
- **响应式设计**: 自适应布局和工具栏
- **主题支持**: 浅色/深色主题切换
- **属性编辑**: 强大的属性编辑器系统

## 🏗️ 技术栈

- **几何内核**: OpenCASCADE 7.9.x
- **UI框架**: Qt 5.14.x + SARibbon
- **数据存储**: SQLite + JSON
- **构建系统**: CMake + Unity Build
- **文件格式**: DXF(libdxfrw)、STEP、IGES、glTF等

## 📖 学习路径

### 🚀 快速开始
1. 阅读 [系统整体架构](01-system-overview.md) 了解系统概况
2. 根据开发需求选择相关模块文档深入学习
3. 参考扩展机制文档进行定制开发

### 👨‍💻 开发者指南
- **核心开发**: 按顺序阅读所有架构文档
- **实体开发**: 重点关注 Entity 和 ExtendData 系统
- **工具开发**: 重点关注 Tool 和 Action 系统
- **界面开发**: 重点关注 UI 系统和属性编辑器
- **BIM开发**: 重点关注 BIM 模块和专业系统

### 🔧 扩展开发
- 使用注册机制添加新的实体类型
- 通过工厂模式扩展交互工具
- 利用动作系统添加用户操作
- 通过扩展数据系统添加自定义属性
- 开发自定义属性编辑器
